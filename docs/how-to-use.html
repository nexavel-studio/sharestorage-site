How to Use
ShareStorage

Two phones, two roles. Set up takes about five minutes — no cloud accounts, no router configuration needed.

1

Install ShareStorage on your old phone

This phone will stay plugged in at home and act as the backup server. It doesn't need a SIM card — WiFi is enough.

2

Open the app and choose Vault mode

On first launch you'll see two modes: Vault and Client. Tap Vault. This mode turns the phone into a local server that other phones can back up to.

3

Pick a storage location and set a space limit

Choose where vault files should be stored — internal storage or an SD card if one is inserted. Then set how much space the vault can use (or leave it unlimited). That's all the setup the vault itself needs.

💡

You can change the storage limit at any time from the vault settings screen.

4

Add people to the vault

Tap + Add Person on the vault home screen for each person you want to give access. Give them a short sign-in name (e.g. "alice"). The app will show you a hand-off card with their sign-in name and the temporary password 0000 — share these with them so they can log in from their phone.

ℹ️

When you add a person, a private storage is automatically created for them. You can also add shared storages from the vault home later.

5

Show the connection QR code

On the vault home screen, under the Vault Server card, tap "Show QR to Connect". This displays the pairing QR that the client phone needs to scan. The QR is only valid while the vault server is running.

💡

You can have multiple storages with different members and limits — one private per person, shared ones for the family, etc.

6

Keep the vault phone on and charging

The vault server runs as a background service. For best results, keep the phone plugged in and connected to your home WiFi. Family members can sync whenever they're on the same network.

1

Get your sign-in name from the vault operator

Before you connect, the person running the vault (the vault operator — usually you or a family member) must add you via "Add Person" on the vault home screen. They'll share a sign-in name and the temporary password 0000 with you.

2

Install ShareStorage and choose Client mode

Install from Google Play. On first launch, tap Client. Client mode is for phones that back up to a vault — it does not run a server itself.

3

Scan the vault's QR code

On the vault phone, open the vault home screen and tap "Show QR to Connect" in the Vault Server card. On your phone, the app will open the camera — scan that QR. Both phones must be on the same WiFi network.

📶

Connection requires both phones on the same local WiFi. Neither phone needs internet access.

4

Log in and set your password

Enter the sign-in name and temporary password 0000 that the vault operator gave you. You'll be prompted immediately to choose your own permanent password. Save the recovery code shown next — write it down somewhere safe. You'll need it if you ever forget your password.

⚠️

Save your recovery code. It's shown once and never stored by the app. Losing it alongside your password means you can't recover your account.

5

Grant photo library access

ShareStorage will ask for permission to access your photos and videos. Grant access so it can read your gallery when you sync.

6

Sync whenever you want

Open the storage in the gallery and tap Sync now to back up new photos and videos to the vault. You can also tap the upload button to pick specific files. Both phones need to be on the same WiFi for sync to work.

✅

Already-uploaded files are never re-uploaded. Sync detects duplicates locally and remotely, so each file is only sent once.
